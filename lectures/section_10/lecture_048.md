# Lecture 48: Displaying with ML/AI Apps

## Key Concepts
- **Session State**: Preserving variables (like chat history) across app reruns using `st.session_state`.
- **Chat UI Elements**: Utilizing `st.chat_message()` to display avatars and roles (user/assistant).
- **Chat Input**: Capturing user prompts via `st.chat_input()`.
- **User Feedback**: Enhancing UX during longer AI generation times using `st.spinner()`.
