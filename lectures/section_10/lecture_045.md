# Lecture 45: Getting Started with Streamlit & Build Your First App

## Key Concepts
- **What is Streamlit?**: An open-source Python library used to create custom web apps for machine learning and data science fast.
- **Execution Model**: Streamlit runs the script from top to bottom every time a user interacts with the app.
- **Basic Commands**: Using `st.title()`, `st.write()`, and `st.set_page_config()` to establish the app's foundation.
- **Running the App**: Launching the server using the CLI command `streamlit run app_name.py`.
