# Lecture 46: Widgets and Interaction

## Key Concepts
- **Input Widgets**: Capturing user input using `st.text_input()`, `st.number_input()`, and `st.slider()`.
- **Selection Widgets**: Providing choices via `st.selectbox()`, `st.radio()`, and `st.multiselect()`.
- **Buttons and State**: Triggering events using `st.button()`. The `if st.button():` pattern evaluates to True only in the exact rerun triggered by the click.
