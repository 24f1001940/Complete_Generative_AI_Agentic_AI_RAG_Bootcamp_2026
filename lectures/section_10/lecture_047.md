# Lecture 47: Displaying Outputs

## Key Concepts
- **Tabular Data**: Rendering interactive Pandas DataFrames with sorting and scrolling via `st.dataframe()`, or static tables with `st.table()`.
- **Metrics**: Highlighting key performance indicators (KPIs) and changes over time using `st.metric()`.
- **Visualizations**: Quick plotting of data using native elements like `st.line_chart()`, `st.bar_chart()`, and `st.area_chart()`.
- **Layout Management**: Organizing outputs side-by-side using `st.columns()`.
