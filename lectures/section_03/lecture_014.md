# Lecture 14: Python Core Concepts (Part 2)

## Key Data Structures
- **Lists (`list`)**: Ordered, mutable collections.
- **Dictionaries (`dict`)**: Key-value pair hash maps.
- **Sets (`set`)**: Unordered collections of unique elements.
- **Tuples (`tuple`)**: Immutable ordered sequences.
- **Comprehensions**: Compact Pythonic syntax for transforming collections.
