## Core Workflow

The lecture can be understood as the following progression:

**Input → Processing → Model / Algorithm → Output**

For this lecture, focus on understanding what each stage does and why it is useful in an AI application.

## Practical Notes

- Understand the purpose of the technique before memorizing APIs.
- Run the corresponding `lecture_101.py` example and inspect the output.
- Experiment with one input at a time and observe how the output changes.
- Keep configuration, credentials, and environment-specific values outside source code.

## What to Remember

- **Concept:** Assemble a first LangChain application from reusable components.
- **Application:** Connect the concept to a real AI/NLP/GenAI workflow.
- **Engineering:** Prefer clear, reusable and testable components.
