Section 21 Open-Source LLM Workflows

Files:
- app.py
- requirements.txt

Install:
1. pip install -r requirements.txt
2. Install Ollama separately if you want local-model demos to actually run.
3. Set GROQ_API_KEY in your environment for hosted API demos.

Run:
streamlit run app.py

Recommended local models for smooth demos:
- llama3.2:3b
- gemma2:2b

Recommended workflow:
- Use the sidebar to switch lectures 115 to 120.
- Record lecture by lecture without editing the file.
