Section 22: Structured Outputs and Tool Use

Files:
- app.py
- requirements.txt
- README.txt
- .env.example

Install:
1) Create and activate a virtual environment.
2) pip install -r requirements.txt
3) Install Ollama separately if you want local-model demos.
4) Set GROQ_API_KEY in your environment for hosted demos.

Run:
streamlit run app.py

Lecture-wise demos:
- Lecture 121: model integration, message types, invoke/batch/stream
- Lecture 122: custom tools and tool-calling
- Lecture 123: structured outputs with Pydantic, TypedDict, dataclasses
- Lecture 124: reliable schema design, fallbacks, and error handling
